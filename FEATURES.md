# Features

What Project World Music adds on top of [GridlessSekai6](https://github.com/UnknownSekai/GridlessSekai6).

## 🎵 Songs
- **Every official song from every server** in one Songs pack: 794 songs, all difficulties, all owned.
  Songs this game version never had come from other servers (EN, TW, KR, CN), with their own charts,
  audio and jackets.
- **One version per song**: the unit's SEKAI version, or else the Virtual Singer / original version.
  The official covers and other singers' versions are left out to save storage (all of them would make
  the Songs pack several times bigger).
- **Cover versions**: extra vocals you pick like any other version in song select (*Cover ver.*).
  ⚠️ Only Adelina's *The Intense Voice of Hatsune Miku* cover fully works right now. The *Our 16bit Wars*
  and *Abelia* covers are totally broken.
- **Result screen covers** for every song, extra songs included.
- **Speed changes work**: slow-downs and speed-ups in charts now play out properly, including some the
  game used to skip.

## 🌐 English
Song titles, artists, singers, version labels and the menus, in English.

## 📥 Chart Import
Paste a Sonolus chart link (Untitled Charts, Chart Cyanvas, sonolus.sekai.best…) and Project World Music turns
it into a playable chart, on your phone, in a minute.

- Runs its converter in Termux, set up once with one copy-paste command
- Importing another difficulty of the same song adds it to the same chart
- Holds and speed changes are adjusted so they play right
- *Remove converter* undoes the setup

## 👥 Co-op
- Rooms over Wi-Fi, no internet needed
- Everyone picks their own difficulty
- Synced start and a shared results screen with everyone's score
- Custom charts are sent to the other players

## 🃏 Card Maker
Make Healer, Perfect Locker and Score Up cards from your own pictures.

## 🎨 Look and feel
- App icon picker (long-press the icon → *App icon*): five icons, or any picture as an extra icon
- New shortcut icons for Import Chart, Card Maker and App icon
- 120 Hz on screens that support it

## 🧹 Removed
Ads, Google Play Games sign-in, the profile picker, gacha and shop.

## 🔧 Fixes
- Solo Live, Chart Maker and Back keep working after a song
- Chart Import setup works on any arm64 phone
- A debug panel that opens by itself after a crash, with the crash log
